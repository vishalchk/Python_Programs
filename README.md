# Python_Programs

Python basics practice: print statements, loops, and simple math functions.

## Files

- `code.py` — print statements, a `for` loop, a `while` loop, and calls to the math functions below. Each output line is prefixed with a number (e.g. `1:`) mapping it back to the command that produced it.
- `math_ops.py` — `add_numbers`, `subtract_numbers`, `multiply_numbers`, `divide_numbers`, `power`, `modulus`, `square_root`, `factorial`, `is_prime`, `reverse_number`, `is_palindrome`, `is_anagram`.
- `string_ops.py` — `is_string_palindrome`, `reverse_string`.

## Run

```
python3 code.py
```
